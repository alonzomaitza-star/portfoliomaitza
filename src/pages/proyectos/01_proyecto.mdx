## Archivo para documentar, mostrar y determinar la pagina para mostrar el proyecto de una plataforma de gestion para invitaciones, estas invitaciones son digitales, para niños, eventos, empresas, etc. El objetivo es poder crear invitaciones personalizadas, con animaciones, videos, imagenes, etc. y que puedan ser compartidas a traves de enlaces, con un contador de visitas y un contador de confirmaciones. ademas de que esta tiene una funcion de recordatorio por whatsapp y correo electronico. Recordemos que tenemos que darle aun usuario plantillas y ya tenemos algo, la ieda es agregar una pagina entonces sobre este proyecto para mostrar en la parte del roadmap.
