# Documentación del Proyecto

Este directorio contiene toda la documentación relacionada con el proyecto Landing Insano.

## Estructura de Carpetas

- `/docs/plan/` - Documentos de planificación y roadmap del proyecto
- `/docs/arquitectura/` - Documentación técnica y de arquitectura
- `/docs/guias/` - Guías de desarrollo y contribución
- `/docs/recursos/` - Recursos adicionales y referencias

## Cómo Contribuir

1. Crea una rama para tu documentación: `git checkout -b docs/nombre-del-cambio`
2. Añade o modifica la documentación necesaria
3. Haz commit de tus cambios: `git commit -m "docs: descripción del cambio"`
4. Sube tus cambios: `git push origin docs/nombre-del-cambio`
5. Abre un Pull Request

## Convenciones de Documentación

- Usa Markdown para todos los archivos de documentación
- Mantén los títulos claros y descriptivos
- Incluye ejemplos de código cuando sea relevante
- Documenta tanto el "qué" como el "por qué" de las decisiones técnicas
